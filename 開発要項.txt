1. システム全体構成
GUI (Front-end): .NET (WPF) / C#

高度なチャート描画（ScottPlot等）と親和性が高く、Windowsネイティブな操作感を実現。

Backend: Python 3.1x

.pai2 (MessagePack形式) のデシリアライズ、NumPyによる高速な配列操作。

連携方式: Process通信 + JSON または Feather (IPC)

C#からPythonスクリプトを引数付きで呼び出し、解析結果を一時ファイル経由で受け取ります。

2. GUI 要項 (C# / WPF)
2.1 ページ1：データ入力
コントロール:

大きな「Drop Area」（Borderコントロール）。

「Browse」ボタン、選択されたパスの表示ラベル。

「Start Analysis」ボタン（解析中はIsEnabled=Falseにする）。

機能:

Drag & Drop: ファイルパスを取得し、拡張子（.pai2）をバリデーション。

画面遷移: スタートクリック後、Pythonプロセスを起動。完了を検知して2ページ目へ遷移。

2.2 ページ2：可視化（2D Map）
コントロール:

ScottPlot または LiveCharts2（大量の点を高速描画可能なライブラリ）。

機能:

Scatter Plot: 横軸(RT)・縦軸(m/z)でプロット。

Peak Interaction: 点をクリックすると、該当データの m/z と RT をポップアップまたはサイドパネルに表示。

ズーム/パン: マウスホイールで特定領域の拡大（MS解析には必須）。

3. バックエンド要項 (Python)
3.1 処理ロジック
デシリアライズ:

msgpack ライブラリを使用。.pai2 はMS-DIAL 5等で使われるバイナリ形式であるため、バイナリを読み込み、Pythonオブジェクト（リスト/辞書）へ復元。

データ抽出:

各ピーク（Spectrum）から、必要なプロパティ（Mass, RetentionTime）のみをリスト内包表記などで高速抽出。

データ整形:

NumPy配列に変換。プロトタイプでは描画負荷を抑えるため、強度（Intensity）によるフィルタリング（閾値以下を捨てる）の実装を推奨。

出力:

C#が読み取りやすい形式（JSON、あるいは高速化を狙うなら .csv や .ftr）で出力。

3.2 必要ライブラリ
msgpack: .pai2のパース用

numpy: 高速な数値配列処理

pandas: データ構造の管理とエクスポート

4. データ連携プロトコル
プロトタイプでは実装の容易さを優先し、以下のフローを採用します。

C#：python.exe script.py "path/to/data.pai2" を実行。

Python：解析完了後、result.json をカレントディレクトリに書き出す。

C#：プロセスの終了を検知し、result.json をデシリアライズしてチャートに流し込む
