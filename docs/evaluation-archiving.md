# LLM検証の終了と保存

終了したローカル検証は `archives/` に保存し、設計・実施用プロンプト・原提出レポート・出力図・付随表・入力由来・実行記録を同時に残す。原提出物は変更せず、閲覧用コピーのリンク補正は区別する。保存対象のコピーとSHA-256照合が完了してから作業用データを削除する。

非公開メタデータや未発表の図を含むアーカイブはGit除外を維持する。削除できない作業物はアーカイブ内の `delete-pending/` に集約し、保存用ファイルとの区別、残存理由、外部リンクの扱いを記録する。元データ保管先と検証用コピーは区別する。

2026-09-10のローカル保存先：`archives/lipidmix-evaluation-20260910/README.md`。削除処理は自動承認レビューで拒否されたため、作業フォルダは削除待ちとして集約した。原本・メタデータ自体はコミット対象に含めない。

評価では実行成功と科学的妥当性を分け、前処理条件の違いを保持する。LLMの提出解釈をそのまま確定した脂質知識としてKBへ登録しない。
