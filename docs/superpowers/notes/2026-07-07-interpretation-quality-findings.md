## ステップ4の結論

1. **7B は解釈担当として不適格（接地の下限割れ）。** 決定的な幻覚を2件生成した:
   - **差次的解析を「火山の標高と地熱活動」と解釈**（volcano plot の "volcano" を火山と誤読し、Spot を地熱スポットとして相関を捏造）。完全なドメイン逸脱。
   - **PCA で検定なしに「有意な差異」表を捏造**（PCA座標4点を根拠なく "有意" と提示）。
   ハルシネーション軸で 2 勝しか取れず、フォールバックに退避しても解釈はさせられない。

2. **think ON は解釈品質を上げる＝ルーティングとは逆の結論。** 完全性16/実用性15 で突出し、総合 16–4 で最良。過去メモリの宿題「think ON の価値」は、ルーティングでは無益だったが**解釈では有益**と決着。多段推論が「次の一手・注意点・網羅」に効く。
   - ただし **think ON には2つのリスク**があり、無条件採用は不可:
     - **言語ドリフト**: 差次的解析の解釈が**英語に流れた**（日本語プロンプト下で）。言語軸は最下位（1勝）。
     - **過剰な作り込みが捏造に転じる**: PCA/POS で **PC1分散比を 63.38%→「50%」と誤記**し、マウスマクロファージ試料に**「葉緑体膜」**等の非接地な生物解釈を上乗せ。冗長化＝過剰主張の温床。

3. **think OFF は「安全だが浅い」。** 正確性9・ハルシネーション8で最良の接地。**n=3 の POS で「群分離なし・サンプル過少」と正しく自制**した（唯一クリーンに退避）。反面、完全性5・実用性4 と物足りない。

4. **含意（モデル運用）**: ローカル解釈担当は **qwen3:14b**（7Bは不可）。**think ON を既定にしつつ、①日本語出力の強制、②「ツール出力の数値を改変しない／記載外の生物学を足さない」制約、③出力長の抑制**をシステムプロンプトで課すのが妥当。制約なしの think ON は完全性と引き換えに捏造・ドリフトを招く。

## ステップ5：エスカレーション集合（将来クラウドへ投げる先の候補）

`summary.json` の `by_phase_axis` と個票所見から、**最良ローカルでも力尽きるフェーズ**を優先度順に:

1. **差次的解析（最優先）** — ローカル全滅。**どのモデルも `summary` の「有意 52/58 件」と群対比（LPS/ILG vs control）を読めず**、巨大な `volcano` 配列に引きずられ「全て ns」と誤読。7B は地熱幻覚、14B(ON) は英語ドリフト。勝ったペアですら本質（有意脂質・生物対比）を外した。
   - **根因は解釈力だけでなくツール出力の形**: `summary`（結論）が先頭にあるのに、後続の全特徴 `volcano` 配列＋8000字切り詰めで結論が埋没。→ **アクション（ツール側で決定的に解決可能）**: `arf_differential` の戻り値を「有意上位＋件数サマリ中心」に整形し `volcano` 全量を削る／要約する。これでローカル解釈が救済され得る（クラウド送り前の第一手）。

2. **PCA の過剰解釈（中）** — 正確性は think OFF(4) が think ON(1) を上回る逆転。think ON が分散比を捏造し生物学を盛る。7B は有意性を捏造。**群依存の生物解釈はクラウド or 決定的サマリで補強**が要る箇所。

3. **QC / 同定 / 文献（低）** — 全モデル健全。接地良好で確信度の留保も適切（同定の msi_level 4、QC の n=3 注意、文献の総説性の明示など）。think ON が完全性・実用性を上乗せするが幻覚は出ない。**当面ローカルで足りる**。

**分界点の暫定結論**: クラウド送りが要るのは実質 **差次的解析（と PCA の生物解釈）**。ただし差次は**まずツール側の出力整形で救済を試す**のが費用対効果最良。実閾値の確定は、`chat_fn` にクラウド腕（例: gpt-4o-mini）を差し込み、同ハーネスで再測して行う（今回はクラウド不使用のため未測）。

## 残課題（人手校正・審判信頼性）

- **人手校正 未実施**: 本結果は Claude Code セッション審判の単独判定。ユーザーが `blind_sheet.md` から十数項目を抜き取り採点し、特に「差次を全滅と見なす採点」「think ON の過剰作り込みを捏造扱いした判断」が専門家判断と一致するか要確認。ズレれば審判信頼性の限界として補正する。
- **B補助（フル run_turn）**: 今回は freeze が実運用と**同一の `execute_tool` ＋ `_truncate(8000)`** を通るよう修正済み（commit 306f159）で、A の凍結入力は run_turn がモデルへ渡す入力とバイト等価。よって別途のフル走行は構成上冗長として省略（乖離ゼロが担保済み）。
- **サンプル規模**: POS 退化により差次は NEG 2コントラストに再配分（5×2直積は崩れ全5フェーズ被覆に緩和）。差次の n が2ケースと薄いので、追試では NEG の別対比（G vs control 等）や ANOVA を足すと安定する。
